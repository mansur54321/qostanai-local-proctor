## Повторить проверки

Из корня проекта после установки зависимостей:

```sh
.venv/bin/python -m pytest -q
.venv/bin/python smoke_cv.py --offline --video
npm --prefix desktop test
```

X11-проверки требуют `Xvfb`, `xvfb-run`, `xdotool` и отдельного виртуального экрана. Из папки `desktop`:

```sh
env -u WAYLAND_DISPLAY PROCTOR_TEST_XVFB=1 XDG_SESSION_TYPE=x11 \
  xvfb-run -n 177 -s '-screen 0 1600x1200x24' \
  npm start -- --smoke-full --video ../demo/fixtures/scenario.avi

env -u WAYLAND_DISPLAY PROCTOR_TEST_XVFB=1 XDG_SESSION_TYPE=x11 \
  xvfb-run -n 178 -s '-screen 0 1600x1200x24' \
  ../.venv/bin/python tests/native_guard_test.py
```

Режимы smoke и нативные тесты отказываются запускаться без явного `PROCTOR_TEST_XVFB=1`, X11 и отдельного DISPLAY. Не подставляйте DISPLAY реального рабочего стола. Отчет полного прохода сохраняется в `docs/desktop-smoke.json`; изображения и короткий список проверок не содержат секретного токена.

## Что эти проверки не доказывают

- Не измерены precision / recall на студентах, точность направления взгляда, чтение с телефона и наведение его камеры на экран.
- Математические тесты знака pitch и положения радужки проверяют геометрию, а не поведение реального человека. MediaPipe сам по себе не определяет точку взгляда на экране; используются относительные эвристики.
- Windows-helper проверен чтением кода и сигнатурами ctypes, без запуска на Windows. Low-level hook может быть снят ОС при таймауте; это ограничение требует проверки на целевом оборудовании.
- Xvfb доказывает перехват сочетаний и снятие захватов, но не заменяет проверку конфликта с оконным менеджером реального компьютерного класса. При конфликте приложение должно отказать в начале защищенного экзамена.
- Wayland не поддерживает защищенный экзамен этого прототипа. CV-просмотр разрешен с явным сообщением ограничения.
- Видео является композицией атрибутированных статичных изображений, не записью экзамена. Источники: `demo/fixtures/ATTRIBUTION.md`.

В Python-тестах остается предупреждение `StarletteDeprecationWarning` о будущей замене httpx в TestClient. Оно не изменило результат: все 21 тест прошли. Сообщения MediaPipe об отсутствии EGL относятся к GPU; используется успешно запущенный CPU runtime.

Проверка anti-slop выполнена основным агентом отдельно от реализации и тестов: [ANTI_SLOP_GATE.md](ANTI_SLOP_GATE.md).
