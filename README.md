# Qostanai Local Proctor

Локальный прототип для кейса №3 КРУ и Qostanai Hub: детекция телефона, контроль лиц и приблизительного направления взгляда, тест в отдельном защищаемом окне. Обработка выполняется на компьютере участника. Облачных API нет.

Команда: **Асемгуль Аманбек и Мансур Акашев**. Qostanai Industry Hackathon 2026.

## Запуск на этом компьютере

Окружение Python и зависимости Electron уже установлены в локальной рабочей папке. Модели включены в проект.

```sh
cd desktop
npm start
```

Камера выключена до кнопки **«Включить наблюдение»**. Сам запуск приложения не включает камеру и не блокирует клавиши. На текущем сеансе Wayland доступен CV; защищенный экзамен требует Windows или Linux X11.

Для демонстрации без камеры:

```sh
cd desktop
npm start -- --video ../demo/fixtures/scenario.avi
```

Это 30 секунд искусственной последовательности: одно лицо, лицо с телефоном, два лица, пустой кадр. Детекции вычисляются настоящими моделями, готовых результатов в видео нет. Калибруйте в первые 10 секунд. Источники и лицензии изображений: [ATTRIBUTION.md](demo/fixtures/ATTRIBUTION.md).

## Установка из репозитория

Нужны Python 3.11, Node.js с npm, веб-камера и интернет только на этапе установки. Проверенное окружение: Python 3.11, CPU PyTorch; Electron 44.7.0. На Windows используйте обычный пользовательский терминал.

Linux:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python bootstrap_models.py
cd desktop
npm ci
npm start
```

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe bootstrap_models.py
cd desktop
npm ci
npm start
```

`bootstrap_models.py` проверяет SHA256 уже включенных моделей; загружает отсутствующие модели только по официальным URL. Во время обработки кадра загрузки нет. Нужен свободный TCP-порт 8765. Electron сам запускает локальный Python-сервер и завершает его при выходе.

## Порядок демонстрации

1. Преподаватель включает наблюдение. Окно показывает фактический источник, кадр, число лиц, уверенность телефона и возраст кадра.
2. Студент смотрит в центр. Кнопка калибровки собирает как минимум пять пригодных кадров с одним лицом и открытыми глазами.
3. Преподаватель задает PIN из 6-12 цифр и включает защищенный экзамен. Можно передать PIN через переменную `PROCTOR_EXIT_PIN`, чтобы студент не задавал его сам. PIN не хранится в журнале.
4. Студент отвечает на три демонстрационных вопроса. Телефон, второе лицо, длительный взгляд в сторону или отсутствие лица создают сигналы для проверки. Сочетания клавиш и потеря фокуса также попадают в журнал.
5. Ответы сохраняются кнопкой отправки. Преподаватель снимает защиту своим PIN и останавливает наблюдение.

Аварийный выход **Ctrl+Alt+Shift+Q** снимает ограничения, останавливает наблюдение и отмечает прерванный экзамен. Это страховка прототипа. Он доступен студенту и потому не является защитой от намеренного прекращения экзамена.

## Что реализовано

| Требование кейса | Реализация и граница |
| --- | --- |
| Телефон в кадре | YOLOv8n, COCO class 67 `cell phone`, порог 0.35. Положение ограничено видимой областью веб-камеры. |
| Поднятие телефона / возможная съёмка | Геометрический флаг: телефон достаточно крупный и поднят на уровень лица. Ориентация камеры телефона и факт фотографии не определяются. |
| Лицо и второе лицо | MediaPipe Face Landmarker, до трех лиц, 478 ориентиров на лицо. COCO не содержит класса лица; YOLO здесь используется для телефона. |
| Взгляд и голова | Смещение радужки и углы головы относительно личной калибровки. Влево/вправо означают стороны незеркального кадра. Это эвристика, не точка фиксации взгляда на экране; прищур и наклон головы влияют на сигнал. |
| Длительный отвод / отсутствие | Событие после 2 секунд непрерывного сигнала. Изменения текущих сигналов тоже записываются; краткий телефон не пропадает из журнала. |
| Alt+Tab, Ctrl+C/V, Win, PrtScn | Нативный helper: XGrabKey на X11, WH_KEYBOARD_LL на Windows. Защита включается только после подтверждения helper. |
| Вкладки и окна | Одно окно Electron; переходы, дополнительные окна, webview и контекстное меню запрещены. Kiosk, перехват клавиш, возврат фокуса. Сторонние процессы не уничтожаются. |
| Работа локально | Модели на диске, CPU inference, сервер только 127.0.0.1, секретный bearer token. Кадры по умолчанию не сохраняются. |

Ограничение ОС существенно: Wayland не дает этому прототипу гарантированно перехватывать системные сочетания. Приложение отказывается начинать защищенный экзамен в таком сеансе. Системный экран безопасности, администратор, внешнее устройство или аппаратная запись экрана остаются вне модели защиты.

## Архитектура и данные

`камера / локальное демо → OpenCV → YOLO + MediaPipe → калибровка и фильтр длительности → журнал JSONL + localhost API → Electron`

Electron main хранит токен и выполняет разрешенные команды через IPC. Renderer работает с sandbox, context isolation, без Node.js и произвольных URL. Нативный helper действует только во время защищенного экзамена. При его сбое защита снимается, наблюдение останавливается, экзамен отмечается прерванным.

Модели предварительно обучены разработчиками компонентов. Команда не обучала собственную модель. Нет данных студентов и результатов учебного пилота. Композиции в `demo/fixtures` проверяют работоспособность, не измеряют точность.

Журнал находится в `sessions/<идентификатор>.jsonl`, содержит время, типы сигналов, события защиты и ответы теста. Файл закрыт от других пользователей ОС там, где доступны POSIX-права. Журнал не публикуется в Git. Видео остается в памяти; после остановки последний кадр может оставаться в памяти процесса до выхода. Биометрическая идентификация и запись аудио отсутствуют.

## Проверки

```sh
.venv/bin/python -m pytest -q
.venv/bin/python smoke_cv.py --offline --video
cd desktop
npm test
```

`smoke_cv.py` открывает только включенные тестовые изображения, не камеру. Сохраняет воспроизводимый результат в `artifacts/cv_smoke.json`. Итоговая область проверки, включая X11, приведена в [docs/VALIDATION.md](docs/VALIDATION.md). Физическая камера, реальный экзамен и Windows на настоящем компьютере требуют проверки командой до Demo Day.
