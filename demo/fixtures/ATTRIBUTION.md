# Источники тестовых изображений

Эти изображения проверяют запуск моделей на статичных примерах. Они не являются записями экзамена и не измеряют точность прокторинга.

`face.jpg`: официальный портрет Barack Obama, 6 декабря 2012 года. Автор: Pete Souza / White House. Изображение уменьшено до 640 × 800. Оригинал: https://upload.wikimedia.org/wikipedia/commons/8/8d/President_Barack_Obama.jpg . Карточка источника и подтверждение public domain (работа сотрудника федерального правительства США): https://commons.wikimedia.org/wiki/File:President_Barack_Obama.jpg .

`two_faces.jpg`: два экземпляра `face.jpg` рядом. Это искусственная композиция для проверки счётчика лиц; в кадре нет двух разных участников.

`phone.jpg`: «A slight difference (phones)», автор TomiTapio, Flickr ID 5737158163: https://www.flickr.com/photos/tomitapio/5737158163/ . COCO val2014, image ID 158122. Лицензия CC BY 2.0: https://creativecommons.org/licenses/by/2.0/ . Изображение сохранено без изменений. Автор и название получены из Flickr oEmbed через публичный relay Noembed; прямые страница и oEmbed Flickr с этого компьютера не отвечали. Запись изображения, лицензия и SHA256 сохранены в `phone_metadata.json`; первичный источник лицензии: официальный архив COCO `annotations_trainval2014.zip`. Ответ oEmbed сохранён в `phone_oembed.json`.

`scenario.avi`: искусственная последовательность из этих изображений: одно лицо, композиция лица с телефоном, два экземпляра лица, пустой кадр. Телефонный фрагмент уменьшен и вставлен рядом с портретом. Для этого фрагмента сохраняется CC BY 2.0; видео не воспроизводит реальное поведение человека. Все детекции в приложении вычисляются моделями при просмотре, предварительно записанных результатов нет.
